# Code of Conduct

Tacet adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. It applies to everyone taking part in the project's spaces: issues, pull requests, discussions and any other project channel.

In short: be respectful and constructive, assume good faith, and do not harass anyone.

## Reporting

Report unacceptable behaviour privately to the maintainers through the repository owner's GitHub profile, or by opening a [private security advisory](../../security/advisories/new) if no other private channel is available. Reports are handled confidentially. Maintainers enforce the code of conduct following the Contributor Covenant's enforcement guidelines.
